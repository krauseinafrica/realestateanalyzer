# Real Estate Analyzer 🏠📊

A comprehensive ROI calculator designed for real estate investors to analyze residential and commercial properties. Built by a Roanoke, VA real estate professional to help investors make data-driven decisions.

## 🎯 Features

### Investment Analysis
- **Cash Flow Calculator** - Detailed monthly income and expense projections
- **ROI Metrics** - Cap rate, cash-on-cash return, and break-even analysis
- **Multi-Property Comparison** - Evaluate and compare up to 5 properties side-by-side
- **10-Year Projections** - Long-term investment visualization

### Research Assistant
- **Integrated Property Search** - One-click access to Zillow, Realtor.com, Homes.com
- **Rental Comps** - Quick links to Rentometer and local rental listings
- **Tax Records** - Direct access to county property tax databases
- **Data Verification** - Compare multiple sources to ensure accuracy

### User Experience
- **Real-time Calculations** - Results update as you type
- **Local Storage** - Save properties for later comparison (no account needed)
- **Mobile Responsive** - Works on desktop, tablet, and mobile
- **Export Ready** - Print or save analysis for sharing
